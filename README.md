# Containers

A Jetpack Compose reference for layout containers — how `Box`, `Row` and `Column` nest, size and align their children.

## Features

- Nested `Box` containers with explicit sizes and colors
- Material 3 theme with light and dark color schemes
- `@Preview` composables for inspecting layouts without running the app

## Tech stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **SDK:** min 24, target 35
- **Package:** `com.example.containers`

<sub>7 source files · 187 lines of code</sub>

## Getting started

```bash
git clone https://github.com/rajabbov/Containers.git
```

Open the folder in Android Studio, let Gradle sync, and run the `app` configuration on a device or emulator.
